Desde la raíz del repo, lanza un contenedor interactivo con Python 3.12 y los servicios montados:
docker run --rm -it \
  --name refresh-news-nlp-pipeline \
  --network compose_net \
  -v "$(pwd)/services:/workspace/services" \
  python:3.12-slim \
  bash
Dentro del contenedor, ejecuta esto:
apt update
apt install -y libpq-dev gcc g++ curl
python -m venv /venv
. /venv/bin/activate
pip install --upgrade pip

Instala solo lo necesario para el --step que vayas a ejecutar.

Para --step threat_classification:
pip install -r /workspace/services/3_database/requirements.txt

Para --step entities:
pip install -r /workspace/services/3_database/requirements.txt
pip install spacy==3.8.0
pip install https://github.com/explosion/spacy-models/releases/download/es_core_news_lg-3.8.0/es_core_news_lg-3.8.0-py3-none-any.whl

Para --step sentiment, --step topics, o si quieres tener todos los pasos disponibles:
pip install -r /workspace/services/2_pipeline_NLP/requirements.txt
pip install -r /workspace/services/3_database/requirements.txt

Ejemplo de ejecución:
python /workspace/services/3_database/refresh_news_entities.py \
  --step threat_classification \
  --host newsdb \
  --port 5432 \
  --dbname newsdb \
  --user myuser \
  --password mypassword

Valores permitidos para --step: entities, sentiment, threat_classification, topics.
