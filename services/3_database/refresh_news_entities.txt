Desde la raíz del repo, lanza un contenedor interactivo con los servicios montados:
docker run --rm -it \
  --name refresh-news-nlp-pipeline \
  --network compose_net \
  -v "$(pwd)/services:/workspace/services" \
  ubuntu:latest \
  bash
Dentro del contenedor, ejecuta esto:
apt update
apt install -y python3 python3-pip python3-venv libpq-dev gcc curl
python3 -m venv /venv
. /venv/bin/activate
pip install --upgrade pip
pip install -r /workspace/services/2_pipeline_NLP/requirements.txt
pip install -r /workspace/services/3_database/requirements.txt
python /workspace/services/3_database/refresh_news_entities.py \
  --step entities \
  --host newsdb \
  --port 5432 \
  --dbname newsdb \
  --user myuser \
  --password mypassword

Valores permitidos para --step: entities, sentiment, threat_classification, topics.
